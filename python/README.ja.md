# Python パッケージ

*[English version](README.md)*

配布物 1 つにつき 1 ディレクトリで、それぞれ単独で pip から入ります。
scm2cpp が生成した C++ を同梱していますが、それはコミット済みのもので
インストール時に生成するのではありません。したがってインストールに必要なのは
コンパイラであって Racket ではありません。各パッケージには、そのソースを
このリポジトリの Scheme から作り直す `regenerate.sh` が付いています。
翻訳器が要るのはそのスクリプトだけです。

| ディレクトリ | パッケージ | 中身 |
|---|---|---|
| `scm2cpp-lasso/` | `scm2cpp-lasso` | Gram 行列に対する lasso。設計行列は任意。CUDA バッチ経路は任意 |
| `scm2cpp-tfs/` | `scm2cpp-tfs` | 移動平均による特徴選択。Gram 構築・降下・予測のいずれも設計行列を作らない |

2 つが重なっているのは意図的です。`scm2cpp-tfs` は `scm2cpp-lasso` に
依存せず降下の複製を自分で持つので、どちらも単独で入ります。両者を分けるのは
「何を知っているか」です。lasso のパッケージは Gram 行列がどこから来たかを
知りません。TFS のパッケージは自分の設計行列が 1 本の系列の移動平均だと
知っており、だからこそ設計行列なしで Gram 行列を作り、予測もできます。
