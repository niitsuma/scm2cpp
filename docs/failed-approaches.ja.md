# 試して捨てたやり方

試したこと、その結果、負けた理由、代わりに採ったものを、作業記録
(`CHANGES.ja.md`。節番号が 2 回出てくる節があるので、節と行で示す)、
`docs/benchmarks.ja.md`、カーネルとパッケージのコメントから集めた。最後の節は、
今も負けている場合の一覧。ここにあるやり方をもう一度試す前に読むこと。たいていは、
今も変わっていない理由で負けている。

|---|---|---|---|---|

## OpenMP(`-P omp`)

| 試したこと | 結果 | 負けた理由 | 代わりに | 出典 |
|---|---|---|---|---|
| いちばん外のループに無条件で指示を付ける | cov-descend の掃引が競合し、係数が 1e56 などになり、毎回違い、何も言わない | 依存の検査がない | ループごとの依存解析 | §24(l.163)、§55(l.947)、§57(l.989) |
| 規模の閾値を低く(`SCM2CPP_OMP_MIN` が 1、次に 1024) | tfs-lasso が 1 スレッドで 1.25 秒、1 / 20 スレッドでは 200 秒超。1024 では負荷 25 のもとで SVC が 0.4 秒から 43 秒 | 短いループごとに並列領域を開く | 仕事量の番人(ループ回数の積)、65536 | §58(l.1042)、§140(l.3557) |
| ループ回数が読めないループに指示を付ける | 数回しか回らない Householder の内側のループで、呼ぶたびにスレッドを起こす | 番人を付けられない | そこには指示を付けない | §140(l.3552) |
| `!(i == n)` と `i = (i+1)` の形のループ | MSVC は前者を拒否。g++ 14 はテンプレートの中で後者を拒否(0.16.0 の wheel が壊れた) | OpenMP の標準形でない | `i < n` と `i += s` | §140(l.3560)、§149(l.3740) |
